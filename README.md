# Random Quote Generator

A simple JavaScript application that displays inspirational quotes from famous authors. Each time the user requests a quote, a random quote is selected from a collection and displayed on the screen.

## Features

- Displays random quotes
- Shows the quote author
- Large collection of inspirational quotes
- Built with vanilla JavaScript
- Lightweight and easy to customize

## Technologies Used

- HTML
- CSS
- JavaScript (ES6 Modules)

## Project Structure

```text
project/
│
├── index.html
├── style.css
├── app.js
└── quotes.js
```

## Usage

1. Clone the repository:

```bash
git clone https://github.com/your-username/random-quote-generator.git
```

2. Open the project folder.

3. Run the project using a local server or open `index.html` in your browser.

## Example Quote Object

```js
{
  quote: "The journey of a thousand miles begins with one step.",
  author: "Lao Tzu"
}
```
